# WebOS3

A playful desktop-style web app that brings a mini operating system to your browser.

Explore the desktop, open apps in floating windows, search the web, play Snake, and try the Python quiz. It also has a camera app. And it has a app called song finder to find any song you want. Please rate my project as well as possible, I work so hard on the projects, to make it more unique. and I used less amount of AI, you can check the code, even if it look a little AI written, but its written by me.

Built with HTML, CSS, and JavaScript.
