WebOS3

A playful desktop-style web app that brings a mini operating system to your browser.

Explore the desktop, open apps in floating windows, search the web, play Snake, and try the Python quiz.

Built with HTML, CSS, and JavaScript.

Link : https://tanzil-alam.github.io/WebOS3/
